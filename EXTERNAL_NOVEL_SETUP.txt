================================================================================
  External Novel Downloader — Setup & Update Guide
================================================================================

This feature lets NpiaDownloader download novels from 100+ non-Novelpia sites
(jjwxc, syosetu, kakuyomu, qidian, etc.) by reusing the open-source
"novel-downloader" browser extension's rule engine.


HOW IT WORKS
------------
NpiaDownloader uses Playwright (headless Chrome) to load the target novel page,
then injects the novel-downloader's compiled JavaScript rules into the page.
The rules extract book metadata, chapter lists, and chapter content — all
without needing the actual browser extension installed.

Three JS files are required in the NpiaDownloader folder:

  gm_stubs.js   — Provides fake Tampermonkey/Greasemonkey APIs so the rules
                   think they're running inside a browser extension.

  bridge.js     — Adapter layer that connects the rules to NpiaDownloader's
                   Python code.

  rules-lib.js  — The compiled novel-downloader rule bundle. This is the file
                   that contains all the site-specific scraping logic.


FIRST-TIME SETUP
----------------
1. Install Playwright (one-time):

     pip install playwright
     playwright install chromium

2. Clone the novel-downloader source (NO fork needed):

     git clone https://github.com/404-novel-project/novel-downloader.git

3. Run the update script from the NpiaDownloader folder:

     update_rules.bat [path_to_novel_downloader]

   Example:
     update_rules.bat D:\Projects\novel-downloader

   This script automatically:
     - Pulls the latest code
     - Applies the bridge-mode patch to src/index.ts
     - Builds the bundle with webpack
     - Copies the result as rules-lib.js


UPDATING THE RULES
------------------
When the novel-downloader project is updated (new sites added, bugs fixed),
just run the same script again:

     update_rules.bat D:\Projects\novel-downloader

That's it! The script handles patching, building, and copying automatically.
No fork maintenance required.


SUPPORTED SITES
---------------
The rule bundle supports 100+ sites including:

  Chinese:   jjwxc, qidian, zongheng, ciweimao, sfacg, 17k, shuhai, tadu,
             gongzicp, linovel, qimao, cool18, and many biquge mirrors
  Japanese:  syosetu (ncode), kakuyomu, alphapolis, akatsuki-novels, novelup
  Korean:    novelpia.jp
  Other:     pixiv, lofter, masiro, readmoo, penana, and more

For the full list, see the novel-downloader project's router file:
  src/router/download.ts


AUTHENTICATION (Enter Browser)
-------------------------------
Some sites require login to access paid/VIP chapters. Use the "Enter Browser"
button in the External Novel Download dialog:

  1. Click "Enter Browser" — a visible Chrome window opens
  2. Navigate to any site and log in normally
  3. Close the browser window when done

Your login session (cookies, localStorage) is saved in the browser_data/
folder and persists across app restarts. The headless scraper reuses this
data, so you stay authenticated without entering credentials again.

SFACG VIP TEXT CHAPTERS
-----------------------
SFACG's VIP text API uses the mobile app session, not only the web browser
session. Use the Enter App button in the external downloader to save a
session_APP cookie. Direct SFACG username/password login can fetch this
automatically; Facebook/third-party linked accounts must paste an app cookie.
Enter App can also open an Android emulator and try importing session_APP
after you log into the SFACG app there. If Android SDK Emulator is missing
on Windows, Open Android will try to download Google's latest Android SDK
Command-line Tools and install the Android Emulator/platform-tools packages.
If Java is missing, it also installs a portable Temurin JDK and sets JAVA_HOME
for the current user.
If no Android Virtual Device exists yet, Open Android will install a compatible
Android system image and create a default Npia Play Store AVD automatically.
For Facebook login, the simplest reliable emulator flow is a Play Store AVD
for logging in, plus a separate root-capable AVD or manual cookie export if
private app data must be read:

  1. Click Enter App > Open Android. The app prefers a Play Store AVD when
     one exists.
  2. Install/open SFACG and Facebook from Play Store inside that emulator.
  3. Log into SFACG with Facebook.
  4. Click Enter App > Import Android if the AVD has su/root available.

If a Play Store AVD was patched with rootAVD and stops booting, click
Enter App > Restore Android to copy ramdisk.img.backup back over ramdisk.img.

Import Android supports both adb-root emulators and rooted Play Store AVDs
where private app data is readable through su/Magisk.

You can also provide one of:

  - Environment variable NPIA_SFACG_COOKIE containing:
      .SFCommunity=...; session_APP=...
  - A file named sfacg_app_cookie.txt next to the app, or in:
      %LOCALAPPDATA%\NpiaDownloader\sfacg_app_cookie.txt
  - config.json keys sfacg_cookie, or sfacg_user + sfacg_pass

The scraper will reuse this app session for api.sfacg.com requests. If no
app session is available, SFACG VIP chapters fall back to the site's image
response.


TROUBLESHOOTING
---------------
  "rules-lib.js not found"
    → Run update_rules.bat to build and copy the rules bundle.

  "X is not defined" on bundle load
    → The bundle expects a library that isn't stubbed. Open gm_stubs.js
      and add a stub for the missing global (similar to the Vue/nunjucks stubs).

  Page timeout / connection errors
    → Some sites may be blocked in your region or behind Cloudflare.
      Try with a VPN or check if the site is accessible in a normal browser.

  "No matching rule for this URL"
    → The site isn't supported by the novel-downloader rules.
      Check the supported sites list above.
